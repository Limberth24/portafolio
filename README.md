# Portafolio - Limberth Mamani Tola

## Descripción del proyecto

Este proyecto es mi portafolio personal como Ingeniero de Sistemas, creado para clientes y empresas que buscan servicios de desarrollo de software, análisis de sistemas y consultoría tecnológica. Hoy no tengo un lugar público y ordenado donde mostrar quién soy, qué servicios ofrezco y los proyectos que he desarrollado; este sitio resuelve ese problema funcionando como mi carta de presentación profesional en internet, donde cualquier persona puede ver mi trabajo y contactarme por formulario o correo sin necesidad de llamar. Está estructurado en secciones claras (Inicio, Sobre Mí, Servicios, Proyectos y Contacto) y desarrollado con HTML, CSS y JavaScript.
