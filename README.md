# Portafolio - Limberth Mamani Tola

## Descripción del proyecto

Este proyecto consiste en el desarrollo de mi portafolio personal, creado para la materia de **Tecnologías en Internet - B**. La idea es construir un sitio web, que me permita presentar quién soy, los servicios que ofrezco, mi proceso de trabajo y los proyectos que he desarrollado. El portafolio estará estructurado en secciones claras (Inicio, Sobre Mí, Proyectos, Servicios, Blog y Contacto) y servirá como una carta de presentación profesional en internet, donde podré mostrar mi trabajo para que sea accesible públicamente y forme parte de mi presencia profesional en la web.
